
# 题解

```c
#include <stdio.h>
int main(){
	int s, v;
	scanf("%d%d", &s, &v);
	int total = 470 - (s + v - 1) / v;
	while (total < 0){
		total += 1440;
	}
	int h = total / 60;
	int m = total % 60;
	printf("%02d:%02d\n", h, m);
	return 0;
}
```

## 想说的话

首先，对于时间类的计算，不包装的最易读写方案，是将时间全部用最小单位表示（题目中的分钟），同样思想见时间戳

其次，题目中用到了向上取整函数 $\lceil a/b \rceil$ 的计算。**初等版**的可以用 `(a + b - 1) / b` 表示，但是可能会遇到溢出问题（a + b 可能是非常大的）。此时可以用**高阶版**：`a / b + (a % b != 0)`，代表向下取整部分加上是否有余数，有则加1（true）

对于负数，同样可以通过这种思想实现向下取整：`(a - b + 1) / b`，不过谁这么闲呢，好想的方法感觉是全部加个偏移放到正半轴

# 原题

# P5707 【深基2.例12】上学迟到

## 题目描述

学校和 yyy 的家之间的距离为 $s$ 米，而 yyy 以 $v$ 米每分钟的速度匀速走向学校。

在上学的路上，yyy 还要额外花费 $10$ 分钟的时间进行垃圾分类。

学校要求必须在上午 $\textrm{8:00}$  到达，请计算在不迟到的前提下，yyy 最晚能什么时候出门。

由于路途遥远，yyy 可能不得不提前一点出发，但是提前的时间不会超过一天。

注意，yyy 只能在每分钟的第 $0$ 秒时出发。

## 输入格式

一行两个正整数 $s,v$，分别代表路程和速度。

## 输出格式

输出一个 $24$ 小时制下的时间，代表 yyy 最晚的出发时间。

输出格式为 $\texttt{HH:MM}$，分别代表该时间的时和分。必须输出两位，不足前面补 $0$。

## 输入输出样例 #1

### 输入 #1

```
100 99
```

### 输出 #1

```
07:48
```

## 说明/提示

对于 $100\%$ 的数据，$1 \le s,v \le 10^4$。
