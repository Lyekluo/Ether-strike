### H1 <stdio.h> 相关

C语言的标准输入输出库，全称为 Standard Input/Output Header，提供了（不全，只放了感觉像认识的）：

- 函数
	- 格式化输出
		- printf（前往stdout）
		- fprintf（任意 FILE \*）
		- sprintf snprintf（字符串，是否限制长度）
	- 格式化输入
		- scanf（来自stdin）
		- fscanf（任意 FILE \*）
		- sscanf（字符串）
	- 单字符读写
		- getchar（来自stdin）
		- fgetc（任意）
		- ungetc（塞回输入流，成为下一次读取的第一个字符）
		- putchar
		- fputc
	- 字符串读写
		- fgets（读一行，会读完'\n'）
	- 二进制读写
		- fread
		- fwrite
	- 文件操作
		- 打开与关闭
			- fopen
			- freopen（重定向流到指定文件）
			- fclose（记得关）
		- 缓冲控制
			- fflush（刷新）
			- setbuf
			- setvbuf（精细控制）
		- 文件定位（光标）
			- fseek
			- ftell
			- rewind
			- fgetpos（存入 fpos_t）
			- fsetpos（用 fpos_t 恢复）
		- 状态查询
			- feof（判断）
			- ferror（判断）
			- clearerr
			- perror
		- 文件管理
			- remove
			- rename
			- tmpfile
			- tmpnam
- 类型
	- FILE（文件流对象）
	- fpos_t（文件位置）
	- size_t（无符号整数类型，用于表示大小）
- 宏
	- 标准流（FILE \*）
		- stdin
		- stdout
		- stderr
	- 常量
		- NULL（0或 (void*)0，空指针）
		- EOF -1
		- etc.
	- 文件定位起点
		- SEEK\_SET
		- SEEK\_CUR
		- SEEK\_END
	- 缓冲模式
		- \_IOFBF
		- \_IOLBF
		- \_IONBF
