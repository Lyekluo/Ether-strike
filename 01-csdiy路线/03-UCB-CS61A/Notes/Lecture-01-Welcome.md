# 欢迎

- Values 值
- Operators 运算符
- Expressions 表达式（包括值和运算符）
	- 字面量、名称、调用

**中缀表示法中的表达式**
- 运算符
- 操作数

**函数表示法**
- 函数接收多个参数
- 嵌套表达式（函数表示和中缀表示都可以）
- 中缀表示可全部转化为函数表示

常见字面量
- 整数 `42`
- 浮点 `3.14, 2e3`
- 字符串 `'CS61A'`
- 布尔值 `True, False`
- 空值 `None`
- 列表 `[1, 2, 3]`
- 元组 `(1, 2)`
- 字典 `{'a': 1}`
- 集合 `{1, 2, 3}`

表达式描述一个计算过程并产生一个值

所有的表达式都能写成调用表达式（Call Expression）
```python
max(1 + 1, 3)
(lambda x: x + 1)(2)
```

嵌套表达式：先求操作符，再**从左到右**求每一个操作数，将函数应用到这些值上，递归执行
